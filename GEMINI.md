# Directives de Développement - Mon Blogprojet

Ce projet est un site web statique composé de HTML, CSS et JavaScript. Veuillez respecter les directives suivantes lors de vos modifications :

## Structure et Code HTML
- Utilisez du HTML5 sémantique (par exemple, `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
- Assurez-vous que toutes les balises d'images possèdent un attribut `alt` descriptif pour l'accessibilité.
- Ne dupliquez pas les identifiants (`id`) et conservez une structure de titres `<h1>`-`<h6>` hiérarchique et logique.

## Style CSS
- Évitez d'utiliser des styles en ligne (inline styles). Toutes les règles de style doivent être écrites dans [style.css](file:///home/americanman/Desktop/Mon-blogprojet/style.css).
- Utilisez des variables CSS pour les couleurs et les polices réutilisables afin de maintenir la cohérence de la charte graphique.
- Assurez-vous que le design est entièrement responsive et adapté aux mobiles.

## JavaScript
- Écrivez du code propre, modulaire et documenté dans [script.js](file:///home/americanman/Desktop/Mon-blogprojet/script.js).
- Utilisez des écouteurs d'événements (`addEventListener`) plutôt que des attributs d'événement en ligne comme `onclick`.

## Directives d'Interaction de l'Agent
- Ne proposez ni n'écrivez jamais de code (exemples, blocs de code ou modifications de fichiers) sauf si l'utilisateur vous en donne explicitement la permission. Suivez strictement les consignes et explications de l'utilisateur.
